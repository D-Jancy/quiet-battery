# 后续任务

当前v0.1.0包含统一原生三页、同源填色设备图标、独立托盘、自启、缓存恢复、默认20%通知周期和标准BAS适配器。实际范围见 [验证记录](VALIDATION.md)。

1. 用真实BAS外设补180F/2A19、订阅、可选2BED充电与断开恢复证据；目前不能宣称任何蓝牙型号已实测。
2. 按 [扩展指南](ADDING_DEVICES.md) 补其他本机外设。同协议先验证或补例外，新协议增加Rust模块，不复制UI或引入动态插件。
3. 有明确需求后再做设备别名、显示顺序和托盘排序。

发布后反馈记录Windows版本、程序版本、型号、连接方式、操作与结果，只保留定位所需数据。不要把待适配型号加入“已支持”宣传。
