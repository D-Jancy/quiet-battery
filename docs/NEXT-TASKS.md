# 后续任务

v0.2.3修复启动失败无可见提示；手动启动显示/恢复主窗口，登录自启保持后台托盘。v0.2.2统一使用LocalAppData保存设置，自动迁移旧数据，状态诊断改为按需内存查询。v0.2.1已保留完整分组的通用 HID 候选与缓存信息及独立被动 HID 诊断导出，新增N3的2.4G查询并修复按钮回退为系统样式的问题。G304已有真机基线；N3本机原始查询与后台程序取得9%；蓝牙已有用户成功反馈及程序BAS读取100%的记录，广播名BT5.0 KB，未确认零售型号。稳定范围与本地开发证据分开见 README 及 [验证记录](VALIDATION.md)。既有截图属于原发布版本。

1. 蓝牙电量已有用户实测反馈；后续有需要时补具体型号、订阅、可选2BED充电与断开恢复记录，不把显示正常推断为所有状态都已验证。
2. 按 [扩展指南](ADDING_DEVICES.md) 用匿名诊断、协议资料和夹具补其他本机外设。同协议先验证或补例外，新协议增加 Rust 模块，不复制 UI 或引入动态插件。非 HID 设备先确定 PnP/传输层，再判断 BAS 或独立协议。
3. 有明确需求后再做设备别名、显示顺序和托盘排序。
4. N3后续补充充电、物理拔插与唤醒恢复等未测场景；已有2.4G真实读取及后台缓存证据。FL980按用户要求搁置，不再主动查询、研究或尝试固件；保留已有调查记录，仍未支持。

发布后反馈记录 Windows 版本、程序版本、型号、连接方式、操作与结果，只保留定位所需数据。默认诊断也应在分享前核对；显式标识符清单、现有 scan/copy 身份和本机原始 validation 不公开。不要把待适配型号加入“已支持”宣传。
